## 🌌 Flagship — Nebula Bot

<div align="center">

<a href="https://github.com/JCVERSA/nebula-p">
  <img src="https://img.shields.io/badge/Nebula%20Bot-nebula--p-8b5cf6?style=for-the-badge&labelColor=0b1026&logo=whatsapp&logoColor=white" alt="Nebula Bot"/>

&nbsp;
<img src="https://img.shields.io/badge/TypeScript-strict-3178C6?style=for-the-badge&labelColor=0b1026&logo=typescript&logoColor=white" alt="TypeScript strict"/>

<div align="center">

**A self-hosted WhatsApp media & AI command center** — VF anime downloader with honest quality labels (~90 MB/ep), screenshot-to-anime identification, new-episode watcher with quiet hours, Gemini AI with NVIDIA NIM fallback, sandboxed panel-created commands, full React web panel. Battle-tested in a ~1 GB container behind a Cloudflare Tunnel — one-line install, idempotent.

`curl -fsSL "https://raw.githubusercontent.com/JCVERSA/nebula-p/main/scripts/install.sh" | sh`

</div>

**Under the hood** — Baileys multi-device · cat-catch style HLS segment downloader → ffmpeg remux · streaming ZIP writer · tokenized 2 h download links · HttpOnly session auth + rate limiting · `manage.sh start/stop/update/doctor` VPS lifecycle · command registry locked by tests.

| 📡 [**air-sahre-apk**](https://github.com/JCVERSA/air-sahre-apk) | **AirQR** — 100% offline air-gapped file transfer for Android (Kotlin + Jetpack Compose): animated QR streams up to 30 FPS, Base45/RFC 9285 encoding, CameraX scanning, SHA-256 integrity, optical feedback beacon |
